## 1. Tecnología Utilizada

La persistencia de datos se implementa con **Spring Data JPA + Hibernate** usando una base de datos **H2 In-Memory** en ambos microservicios.

| Componente | MS Notas | MS Asistencia |
|---|---|---|
| ORM | Hibernate (vía JPA) | Hibernate (vía JPA) |
| Base de datos | H2 In-Memory (`notasdb`) | H2 In-Memory (`asistenciadb`) |
| Estrategia DDL | `create-drop` | `create-drop` |
| Puerto | 8081 | 8082 |

## 3. Entidades JPA

### 3.1 NotaModel

```java
@Entity
@Table(name = "notas")
@Data                              // Lombok: getters, setters, equals, hashCode
public class NotaModel {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;               // Clave primaria auto-incremental

    private Long alumnoId;         // FK lógica al alumno (sin relación JPA)
    private String nombreAlumno;
    private String curso;
    private String asignatura;
    private String tipoEvaluacion; // PRUEBA, TAREA, EXAMEN, etc.
    private Double nota;           // 1.0 – 7.0
    private LocalDate fechaEvaluacion;
    private String observaciones;

    @PrePersist
    protected void onCreate() {
        if (fechaEvaluacion == null) fechaEvaluacion = LocalDate.now();
    }
}
```

**Schema SQL generado automáticamente:**
```sql
CREATE TABLE notas (
    id               BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    alumno_id        BIGINT,
    nombre_alumno    VARCHAR(255),
    curso            VARCHAR(255),
    asignatura       VARCHAR(255),
    tipo_evaluacion  VARCHAR(255),
    nota             DOUBLE,
    fecha_evaluacion DATE,
    observaciones    VARCHAR(255)
);
```

### 3.2 AsistenciaModel

```java
@Entity
@Table(name = "asistencia")
@Data
public class AsistenciaModel {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private Long alumnoId;
    private String nombreAlumno;
    private String curso;
    private LocalDate fecha;

    @Enumerated(EnumType.STRING)
    private EstadoAsistencia estado;   // PRESENTE | AUSENTE | JUSTIFICADO

    private String docente;
    private String observaciones;

    public enum EstadoAsistencia { PRESENTE, AUSENTE, JUSTIFICADO }
}
```

**Schema SQL generado automáticamente:**
```sql
CREATE TABLE asistencia (
    id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    alumno_id     BIGINT,
    nombre_alumno VARCHAR(255),
    curso         VARCHAR(255),
    fecha         DATE,
    estado        VARCHAR(20),    -- almacena 'PRESENTE', 'AUSENTE', 'JUSTIFICADO'
    docente       VARCHAR(255),
    observaciones VARCHAR(255)
);
```

## 4. Repositorios JPA

### 4.1 NotaRepository

```java
public interface NotaRepository extends JpaRepository<NotaModel, Long> {
    List<NotaModel> findByAlumnoId(Long alumnoId);

    @Query("SELECT AVG(n.nota) FROM NotaModel n WHERE n.alumnoId = :alumnoId")
    Double calcularPromedioAlumno(@Param("alumnoId") Long alumnoId);
}
```

**Métodos disponibles (heredados de JpaRepository):**
- `findAll()` — SELECT * FROM notas
- `findById(id)` — SELECT * FROM notas WHERE id = ?
- `save(entity)` — INSERT o UPDATE automático
- `deleteById(id)` — DELETE FROM notas WHERE id = ?
- `findByAlumnoId(id)` — query derivada de nombre de método
- `calcularPromedioAlumno(id)` — JPQL personalizado con `@Query`

### 4.2 AsistenciaRepository

```java
public interface AsistenciaRepository extends JpaRepository<AsistenciaModel, Long> {
    List<AsistenciaModel> findByAlumnoId(Long alumnoId);

    @Query("SELECT COUNT(a) FROM AsistenciaModel a WHERE a.alumnoId = :id AND a.estado = 'PRESENTE'")
    Long contarPresencias(@Param("id") Long alumnoId);

    @Query("SELECT COUNT(a) FROM AsistenciaModel a WHERE a.alumnoId = :id AND a.estado = 'AUSENTE'")
    Long contarAusencias(@Param("id") Long alumnoId);

    @Query("SELECT COUNT(a) FROM AsistenciaModel a WHERE a.alumnoId = :id")
    Long contarTotal(@Param("id") Long alumnoId);
}
```

## 5. Flujo de Persistencia

```
[Frontend React]
       │
       │ POST /api/notas  (JSON body)
       ▼
[NotaController.registrar(NotaModel nota)]
       │
       │ notaService.registrarNota(nota)
       ▼
[NotaService.registrarNota()]
       │
       │ notaRepository.save(nota)
       ▼
[JPA / Hibernate]
       │
       │ INSERT INTO notas (alumno_id, nombre_alumno, ...) VALUES (?, ?, ...)
       ▼
[H2 In-Memory DB: notasdb]
       │
       │ Retorna entidad con id generado
       ◄────────────────────────────────
```

## 6. Garantías de Persistencia

| Mecanismo | Garantía |
|---|---|
| `@Transactional` (implícito en Spring Data) | Las operaciones de escritura son atómicas |
| `ddl-auto=create-drop` | El schema se recrea en cada inicio (datos frescos) |
| `@PrePersist` | La fecha se auto-asigna si no se proporciona |
| `@Enumerated(EnumType.STRING)` | El estado se almacena como texto legible |
| `show-sql=true` | Toda operación SQL es visible en logs para depuración |
| `JpaRepository.save()` | Detecta automáticamente INSERT vs UPDATE por el id |
